# Changelog

All notable changes to Netmapper-Z will be documented in this file.

## [1.0.0] - 2026-03-30
### Added
- Initial release of Netmapper-Z hybrid framework.
- Core passive OSINT modules (WHOIS, crt.sh, Shodan).
- Active Nmap wrappers (Port scanning, OS fingerprinting, NSE scripts).
- FastAPI REST interface and Docker support.
